# Задание 1 — HTML и CSS

Семантическая страница «Выбор даты и времени»: header, nav, main, section, aside, footer. Календарь октября 2026, выбранное 31 число, сегодняшнее 24 число, слоты 12:00, 16:00, 17:00 и занятый 18:00. Сводка услуги, мастер, длительность, цена, нижняя панель, контакты. CSS вынесен отдельно, использованы Grid и Flexbox, hover и focus-visible. Есть адаптивные варианты для планшета и телефона. Это статическая практика: переключение дат и времени реализовано в следующей версии.

## Запуск

Откройте index.html двойным кликом. Установка зависимостей не нужна.

## Данные и макет

Экран из учебного проекта «Контур». Макет: https://www.figma.com/design/ZpkkCic8gGMsrm244NVDWQ

Учебное «сегодня» — 24 октября 2026, выбранная дата по умолчанию — 31 октября. В задании разрешена фиксированная дата для проверки. Эти даты заданы в исходниках проекта. Имена, цены, адрес и отзывы учебные. Реальной записи и отправки контактов нет.

На данной странице сверстан только выбор даты и времени. Навигация шапки ведёт к соответствующим блокам этой страницы. «Продолжить» в интерактивных версиях показывает выбранные данные в диалоге; дополнительные страницы пути записи не входят в эти задания.

## Проверки

Визуальный осмотр при ширине 1440 и 390 пикселей. Горизонтального переполнения нет. Проверены семантические теги, отдельный CSS и отсутствие inline-стилей в исходном HTML.

## Сдача

Перенесите папку `frontend-1-practice` в свой учебный Git-репозиторий. Проверьте `git status`, добавьте нужные файлы через `git add frontend-1-practice`, выполните commit и push в свою ветку. В ответе преподавателю укажите ссылку на эту папку в своём репозитории. Удалённый репозиторий в исходных материалах не задан, поэтому публикация здесь не выполнялась.

Зависимости node_modules в архив не включены. Для React включён pnpm-lock.yaml с зафиксированными зависимостями.
